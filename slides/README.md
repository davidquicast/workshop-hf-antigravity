# Presentación de 22 slides

[Presentación pública](https://huggingface.co/spaces/davidquicast/devfest-cusco-2026-ai-security).
Código React/TypeScript del recorrido aprobado, con estilos DevFest y traducción ES/EN.

Desde la raíz: `npm ci --prefix slides`, `npm run build --prefix slides` y
`npm run dev --prefix slides`. Abrir http://localhost:4173/ .

En Windows: `py slides/scripts/serve.py`. Para los requisitos y la exportación opcional
a PDF/PPTX consulta [REPRODUCIR.md](../docs/REPRODUCIR.md).

El runtime de referencia se conserva en vendor/reference/assets; sus créditos y los de
los recursos de terceros están en [ATTRIBUTION.md](../ATTRIBUTION.md).
